# ISP Atlas · 图像信号处理可视化系统

一个**纯浏览器端、零依赖**的图像信号处理（ISP）教学与验证系统：
把相机 ISP 的传统算法与深度学习前沿放进同一个系统里，全部核心算法为原生 JavaScript 手写实现（无 OpenCV / 无第三方库）。

## 运行方式

直接双击打开 `index.html` 即可（无模块、无跨域请求，file:// 协议可用）。

也可以用本地服务器：

```bash
cd ispatlas
python -m http.server 8931
# 打开 http://localhost:8931
```

## 系统组成

| 页面 | 内容 |
|---|---|
| **总览** | 系统介绍 + 可点击的流水线全景图 |
| **ISP 流水线** | 传感器 RAW 模拟（RGGB 马赛克 / 光谱串扰 / 色温偏移 / 读出噪声 / 坏点 / 镜头阴影）→ 黑电平 → 坏点校正 → AWB（3 种算法）→ 去马赛克（双线性 / 边缘自适应+色差平滑）→ 降噪（双边 / 中值）→ CCM → Gamma → USM 锐化 → 色彩增强。每级可开关、可调参、前后对比滑块，最终输出实时计算 PSNR / SSIM |
| **基础算法库** | 灰度 / 直方图均衡 / CLAHE / 高斯 / 中值 / 双边 / 非局部均值 / Sobel-Laplacian / Canny / Otsu / 形态学 / 噪声与评估，共 12 个可交互 Demo |
| **深度学习图鉴** | 8 大领域 × 18 个代表模型（SID / ELD / PMN / DnCNN / NAFNet / Restormer / DMCNN / AirNet / PromptIR / AdaIR / SwinIR / HAT / MIMO-UNet / Deep-ISP / Invertible-ISP / MAI Learned ISP / Zero-DCE / SCI / Retinexformer），自绘 SVG 结构图 + 逐模块解读 + 数据集/损失/指标 + 开源仓库 + 简历提示 |
| **简历工程** | 3~4 个月研究路线图（传统 → 深度 → 部署），单卡（4090/3060）可行项目与简历条目模板 |

## 工程亮点（面试可讲）

1. **物理正确的传感器模拟**：sRGB 线性化 → 光谱串扰（CCM 有真实的校正对象）→ CFA 采样 → 色温偏移 → 噪声 → 镜头阴影；坏点采用 ADC 上下溢出（rail）检测而非"偏离中值"判定，避免误杀高频纹理。
2. **线性域处理链**：去马赛克之后的线性流水线全程 Float32 传递，8-bit 量化只发生在 Gamma 编码之后——避免暗部信息被中间量化摧毁。
3. **CCM 取串扰矩阵的严格逆**：数值可验证 CCM·XT = I；同时展示"CCM 会放大插值误差"这一真实现象（正是 DMCNN 等联合处理研究的动机）。
4. **自绘 SVG 结构图渲染器**：所有模型结构图（含 U-Net 跳连弧线、横向流水线）由统一规范的内置渲染器生成，非截图。
5. **传统 ↔ 深度对照**：每个深度学习领域配一张"传统算法近似效果示意"，用系统内置经典算法模拟该领域模型要解决的问题。

## 目录结构

```
ispatlas/
├── index.html        # 单页入口（顶部导航，无侧栏）
├── css/style.css     # 清爽雅致浅色主题（象牙白 + 鼠尾草绿）
└── js/
    ├── imgproc.js    # 核心算法库（约 1200 行，全部手写）
    ├── utils.js      # 程序化测试场景 / 对比滑块 / 通用 UI
    ├── archviz.js    # 模型结构图 SVG 渲染器
    ├── ai-data.js    # 深度学习模型图鉴数据
    ├── pipeline.js   # ISP 流水线交互页
    ├── basics.js     # 基础算法 Demo 页
    ├── ai.js         # 深度学习图鉴页
    └── main.js       # 导航路由与页面惰性初始化
```

## 说明

- 深度学习部分的指标均为论文自报数值（约值），仅供学习参考；模型不在浏览器内运行。
- 深度学习领域的"效果示意"由内置传统算法近似生成，已明确标注，非模型真实输出。
